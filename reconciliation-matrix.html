Billing reconciliation matrix

Map the symptoms to the Anthropic systems that need owner review.

A privacy-sanitized matrix for reporters, support reviewers, and a human Anthropic Billing Platform / payment-operations owner. It separates the observed customer failure from related public patterns so the case is not dismissed as a generic card decline.

Core Contradiction

Manual prepaid Claude usage-credit purchases fail or lose the advertised discounted checkout state, while automatic usage-credit top-ups from the same saved billing setup continue charging successfully. That contradiction needs cross-system reconciliation, not another generic update-payment-method answer.

Minimum Owner Query

  • Compare the same account's manual usage-credit checkout records against automatic top-up records.
  • Confirm whether any failed manual purchase consumed discount eligibility or created hidden payment/order state.
  • Trace the checkout through payment confirmation, purchase commit, invoice/order creation, and credit-ledger provisioning.
  • Confirm whether CLI or UI limit messages route the user to credits when spend-limit or plan quota state is the actual blocker.
  • Confirm whether environment tokens, stored API keys, or account/org binding can silently change the billing source away from the paid subscription.
  • Confirm whether Fin/support account lookup sees the same paid plan and organization state as Claude web, desktop, Console, and Claude Code.
  • Confirm the working support route for payment-operations review, because the failed-payment sender reply path bounced as address-not-found.

Privacy Boundary

This public matrix intentionally omits card endings, bank names, payment processor object IDs, invoice or receipt identifiers, raw browser/network logs, screenshots, payment URLs, one-time codes, private support-thread bodies, addresses, identity documents, document numbers, and agency report numbers.

Independent public packet. Not an Anthropic statement. Sensitive evidence should only be shared through safer channels with authorized reviewers or reporters when necessary.
